# CopyRAG

RAG application with a .NET backend and React frontend.

## Clone And Copy Project

1. Clone the repository:

```bash
git clone https://github.com/manishbhusal7/RAGAI.git
```

2. Move into the project folder:

```bash
cd RAGAI
```

3. Copy environment template to local env file:

```bash
cp Backend/environment.template Backend/.env
```

4. Update `Backend/.env` with your real credentials.

## Run Frontend

```bash
npm install
npm start
```

## Run Backend

```bash
cd Backend
dotnet restore
dotnet run
```
